📦 Sistema de Controle de Estoque

Sistema de gerenciamento de estoque desenvolvido em Python como parte dos meus estudos em programação.

🚀 Funcionalidades

- Cadastro de produtos.
- Consulta de produtos cadastrados.
- Remoção de produtos.
- Controle de quantidade em estoque.
- Registro de vendas.
- Atualização automática do estoque após vendas.
- Cálculo do valor total do estoque.

🛠️ Tecnologias utilizadas

- Python 3
- PyCharm
- GitHub

▶️ Como executar

1. Tenha o Python 3 instalado.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto.
4. Execute o arquivo:

python estoqueprotecao.py

🎯 Objetivo

Este projeto foi desenvolvido para praticar lógica de programação, estruturas condicionais, laços de repetição, funções e manipulação de dados em Python.
